# 📖 Manual del Sistema: Resumen de Guías de Usuario

Este directorio contiene las guías de uso oficiales y detalladas para cada uno de los roles dentro del Sistema de Gestión de Casos de la Defensoría de la Niñez y Adolescencia (DNA).

El sistema fue diseñado bajo el principio fundamental de que **el caso pertenece al Niño, Niña o Adolescente (NNA)**. Los profesionales y las oficinas son temporales, y su trabajo converge en una **Línea de Tiempo Unificada** que ofrece un historial inmutable y auditable.

---

## 👥 Guías Oficiales por Rol

Selecciona tu rol para acceder a la guía completa correspondiente:

### 👑 [Guía para Jefatura de Unidad](./GUIA-JEFATURA.md)
*Supervisión general, asignación de equipo interdisciplinario, control de flujo del caso, aprobación de informes y monitoreo de intervenciones.*

### ⚖️ [Guía para Abogado / Área Legal](./GUIA-ABOGADO.md)
*Evaluación de conciliabilidad (Arts. 24, 26, 27 - Ordenanza 136/03), tipicidad penal (con IA local), plazos procesales, emisión de citaciones, medidas de protección y audiencias de conciliación.*

### 🧠 [Guía para Psicólogo / Área Psicológica](./GUIA-PSICOLOGO.md)
*Evaluación psicológica inicial, extracción de indicadores de trauma, prellenado de escalas de riesgo, traducción clínica, plan de sesiones de acompañamiento y manejo de evidencia sensible.*

### 🏡 [Guía para Trabajador Social / Área Social](./GUIA-SOCIAL.md)
*Ingreso de Ficha Social (que pasa el caso a EVALUACIÓN), familiogramas (estructura familiar), mapeo ambiental (visitas domiciliarias), evaluación de vulnerabilidad y plan de intervenciones.*

### 📝 [Guía para Secretaría](./GUIA-SECRETARIA.md)
*Ingesta inicial de casos (fase DERIVACION), búsqueda e integración con el Directorio de Personas, agenda de citas/entrevistas y gestión de accesos al Portal Externo para tutores.*

### 🛡️ [Guía para Portal de Tutores (Portal Externo)](./GUIA-PORTAL-TUTORES.md)
*Seguimiento del estado del expediente en tiempo real y consulta de citas/audiencias agendadas para tutores y referentes legales del NNA.*

### 🛠️ [Guía para Administrador](./GUIA-ADMINISTRADOR.md)
*Gestión de usuarios, asignación de roles y permisos, mantenimiento de catálogos configurables, configuración de módulos de IA y auditoría del sistema.*
