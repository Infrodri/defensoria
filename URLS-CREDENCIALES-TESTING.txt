🧪 TESTING RÁPIDO CON cURL
──────────────────────────

1. LOGIN:
   curl -X POST http://localhost:4000/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"abogado@defensoria.gob.bo","password":"Password123!"}'
   
   # Copiar el "accessToken" de la respuesta

2. USAR TOKEN:
   curl -X POST http://localhost:4000/api/legal-tools/discrepancies/analyze \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer YOUR_TOKEN" \
     -d '{
       "caseId": "YOUR_CASE_ID",
       "transcriptionId": "YOUR_TRANS_ID"
     }'

3. OBTENER IDs:
   curl -X GET http://localhost:4000/api/cases \
     -H "Authorization: Bearer YOUR_TOKEN"
